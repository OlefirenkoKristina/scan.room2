# scan.room2

Одна кімната, зібрана в Blender зі сканів Polycam та Scaniverse.

## Вихідні дані
- `10.10.2026.glb` — кімната (Polycam), основа сцени
- `Scaniverse 2026-10-10 140603.glb` — та сама кімната (Scaniverse), суміщена ICP (прихована в сцені)
- `Scaniverse 2026-10-10 142409.glb` — полиця з продуктами
- три `.glb` з Polycam з кириличними назвами — шафа з книгами, її бік, стіна з картинами й полицею
- `photo_*.jpg` — фото-референси (у 3D не імпортуються)

## Результат
- `room_v3.blend` (Git LFS) — фінальна сцена: стіни/підлога/стеля вирівняні, додана текстурована оболонка `Room_shell`
- Колекції: `Room_Polycam`, `Room_Scaniverse_aligned_(hidden)`, `Objects` (полиця + стіна з картинами), `Unplaced_duplicates_(hidden)`, `Room_shell`

## Історія робіт
1. Суміщення Scaniverse-кімнати з Polycam-кімнатою: масштаб 0,987, похибка ≈5 см (`scripts/icp.py`, `t1.json`).
2. Розстановка окремих предметів пошуком положення + ICP (`obj*.py`, `objs3.json`). Шафи з книгами вже є в кімнатному скані, тому їх копії приховано.
3. Побудова сцени (`build.py`, `build2.py`), вирівнювання стін і оболонка з текстурами (`flat2.py`).

Скрипти запускаються так: `blender -b -P script.py`. Шляхи в них прописані під локальний комп'ютер.
